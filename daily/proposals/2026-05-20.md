## Risk

- Breaking change? **No** — both items add metadata or tighten a value
  range; no public API renames.
- Migration needed? **No.**
- Affects driftbench-web? **No.**
- Affects Driftbench-demo claims? **No** (cs_warehouse_sk range isn't
  referenced; categorical detection is a behind-the-scenes hint).

## Why this, why now

The b8 release just shipped CSV headers + spec/Python parity, and the daily
pipeline itself is brand new — the first run should pick low-risk items
from TODO so any pipeline bug is easy to separate from feature breakage.
Both items are pre-existing TODOs with obvious tests.
